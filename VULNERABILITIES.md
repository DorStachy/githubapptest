# Seeded Vulnerabilities (21)

This repo intentionally includes 21 insecure patterns to validate scanner detection and backend processing.

1. SQL injection in string-concatenated query (`/login`)
2. Command injection via `exec` (`/run`)
3. Command injection via `execSync` (`/run-sync`)
4. Path traversal in file serving (`/file`)
5. Open redirect (`/goto`)
6. Reflected XSS (`/search`)
7. Arbitrary code execution via `eval` (`/execute-rule`)
8. Prototype pollution risk via `Object.assign` from request body (`/merge-profile`)
9. Weak hash algorithm MD5 (`/hash`)
10. Weak cipher 3DES (`/encrypt`)
11. Predictable randomness (`/token`)
12. Hardcoded JWT secret (`JWT_SECRET`)
13. Insecure cookie flags missing `HttpOnly`/`Secure` (`/session`)
14. CSRF-prone state-changing GET endpoint (`/transfer-funds`)
15. SSRF via user-controlled URL fetch (`/fetch-url`)
16. NoSQL injection by passing raw request body into `findOne` (`/mongo-login`)
17. LDAP injection in interpolated LDAP filter (`/ldap-search`)
18. TLS certificate verification disabled (`/tls-proxy`)
19. Arbitrary file write path construction (`/save-script`)
20. Exposed secret material in config response (`/config`)
21. Hardcoded cloud credentials (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `.env.example`)
